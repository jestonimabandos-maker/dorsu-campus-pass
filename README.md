\# DOrSU Digital Campus Pass



\## ITMSD1 Laboratory 03



The \*\*DOrSU Digital Campus Pass\*\* is a simple mobile application developed using React Native, Expo, and TypeScript. It demonstrates how components, TypeScript props, state management, and mobile UI styling can be combined to create a functional digital student campus pass.



\## Technologies Used



\- React Native

\- Expo SDK 57

\- TypeScript

\- JavaScript / JSX

\- React Hooks (`useState`)

\- StyleSheet

\- Flexbox



\## Features



\- Digital student identification pass

\- Student profile information

\- Student ID number and program

\- Active and suspended access status

\- Campus gate scan counter

\- Reset scan counter

\- Access status toggle

\- Peer student demonstration

\- Mobile-friendly layout



\## Laboratory Exercises



This project was developed through six exercises:



1\. \*\*Expo Scaffolding, Metro \& Fast Refresh\*\*

&#x20;  - Created the Expo project and tested the development environment.



2\. \*\*Core Primitives \& JSX Anatomy\*\*

&#x20;  - Used React Native components such as `View`, `Text`, `Image`, and `Pressable`.



3\. \*\*Modular Components \& TypeScript Props\*\*

&#x20;  - Created reusable components and passed student information using TypeScript props.



4\. \*\*Dynamic State Management with useState\*\*

&#x20;  - Added interactive features such as the gate scan counter and access status.



5\. \*\*StyleSheet \& Flexbox\*\*

&#x20;  - Used `StyleSheet.create()` and Flexbox to organize the mobile interface.



6\. \*\*Synthesis Challenge: DOrSU Digital Campus Pass\*\*

&#x20;  - Combined the concepts from the previous exercises into one working application.
